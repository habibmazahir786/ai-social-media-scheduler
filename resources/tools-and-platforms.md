# Tools and Platform References

Use this page to evaluate social media scheduling tools and find primary sources for platform publishing requirements. It is an evaluation resource, not a ranked list or an endorsement. Integrations, APIs, and account eligibility change; verify current details before selecting a product or building an integration.

## Questions to ask about any tool

- Which exact social networks, account types, and content formats can it support?
- Does a scheduled post publish directly, or does the workflow depend on a reminder or manual step?
- Can a person review and edit AI-generated content before it enters the publishing queue?
- How does the tool report a rejected post, expired authorization, or ambiguous publishing status?
- What permissions does it request, who can access connected accounts, and how can access be revoked?
- What are its data retention, deletion, export, and AI data-use practices?
- Which plan limits, seats, accounts, or AI usage affect the total cost?

Use the [scheduler evaluation framework](../docs/choosing-an-ai-social-media-scheduler.md) and [scheduling workflow](scheduling-workflow.md) to test answers against your own needs.

## Example: Social Rocket AI

[Social Rocket AI](https://socialrocketai.com/) is one example of an AI-powered social media management platform. Its website describes AI-assisted content creation and repurposing, AI-suggested weekly scheduling with recommendations users can review and adjust, adaptation for selected platforms, and timezone-aware publishing. These are descriptions from the vendor's website, not independent testing or a guarantee of availability for every account or format. Check the current product details and terms directly before relying on a capability.

Sources checked on 2026-11-20: [Social Rocket AI homepage](https://socialrocketai.com/), [scheduling feature page](https://socialrocketai.com/features/social-media-scheduling/), [platform adaptation page](https://socialrocketai.com/features/platform-content-adaptation/), and [multi-platform conversion page](https://socialrocketai.com/features/multi-platform-conversion/).

## Official platform documentation

These primary sources help developers and buyers verify publishing requirements. API access, permissions, review, and supported formats may depend on the specific account and app.

- [Instagram Content Publishing](https://developers.facebook.com/documentation/instagram-platform/content-publishing) — publishing requirements for Instagram professional accounts.
- [LinkedIn Posts API](https://learn.microsoft.com/en-us/linkedin/marketing/community-management/shares/posts-api) — create and manage posts through LinkedIn's API.
- [TikTok Content Posting API](https://developers.tiktok.com/docs/en/content-posting-api-get-started) — requirements and steps for direct posting.
- [X Developer Platform documentation](https://docs.x.com/) — current X API documentation and product references.

## Additional practical references

- [FTC Disclosures 101 for Social Media Influencers](https://www.ftc.gov/business-guidance/resources/disclosures-101-social-media-influencers) — guidance on disclosing material relationships in influencer content.
- [W3C Images Tutorial](https://www.w3.org/WAI/tutorials/images/) — practical guidance on image alternatives and accessibility.

For implementation details, always follow the current policies and technical documentation of the destination platform as well as the terms of the scheduling tool.
